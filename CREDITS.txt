MAP DATA
Natural Earth, Admin 0 Countries, scale 1:110 million.
177 geographic features with generalized coastlines and boundaries.
Source: https://github.com/nvkelso/natural-earth-vector
File: geojson/ne_110m_admin_0_countries.geojson
Downloaded: 2026-09-10.
Website: https://www.naturalearthdata.com/
Terms: https://www.naturalearthdata.com/about/terms-of-use/
Natural Earth map data is in the public domain.
Label coordinates and original Dutch names come from the source dataset.
js/locale.js supplies English display names without changing feature IDs.
Boundaries follow the source; small countries and islands are not all
individually visible at this scale.

MAP RENDERING
D3.js 7.9.0, ISC license.
https://d3js.org/
https://github.com/d3/d3
The complete bundled license is in vendor/D3-LICENSE.txt.
Projections: geoOrthographic and geoNaturalEarth1.
Libraries and map data are bundled locally. Gameplay does not request
external map services or CDN files.

PROJECT
Orbit Pact, an improved version of the supplied browser game.
The interface uses system fonts and built-in line icons.
